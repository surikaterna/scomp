# @scompr/transport-browser-windows

> Part of the sComPR framework (formerly "scomp")

Browser window messaging transport for scomp.

Requires `@scompr/core` and `@scompr/transport-shared` as peer dependencies.

## Installation

```bash
npm install @scompr/transport-browser-windows
# or
bun add @scompr/transport-browser-windows
```

## Usage

```ts
import { BrowserWindowTransport } from "@scompr/transport-browser-windows";
```

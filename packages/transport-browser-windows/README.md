# @scomp/transport-browser-windows

Browser window messaging transport for scomp.

Requires `@scomp/core` and `@scomp/transport-shared` as peer dependencies.

## Installation

```bash
npm install @scomp/transport-browser-windows
# or
bun add @scomp/transport-browser-windows
```

## Usage

```ts
import { BrowserWindowTransport } from "@scomp/transport-browser-windows";
```

# @scomp/transport-rabbitmq

RabbitMQ transport for scomp.

Requires `@scomp/core` and `@scomp/transport-shared` as peer dependencies.

## Installation

```bash
npm install @scomp/transport-rabbitmq
# or
bun add @scomp/transport-rabbitmq
```

## Usage

```ts
import { RabbitMQTransport } from "@scomp/transport-rabbitmq";
```

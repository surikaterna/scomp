# @scompr/transport-rabbitmq

> Part of the sComPR framework (formerly "scomp")

RabbitMQ transport for scomp.

Requires `@scompr/core` and `@scompr/transport-shared` as peer dependencies.

## Installation

```bash
npm install @scompr/transport-rabbitmq
# or
bun add @scompr/transport-rabbitmq
```

## Usage

```ts
import { RabbitMQTransport } from "@scompr/transport-rabbitmq";
```
